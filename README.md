# EteroTV

Catálogo IPTV con favoritos y progreso al estilo Netflix. Reproduce en VLC.

- **Android (celular, Google TV, Fire TV):** `eterotv-<versión>.apk` del último Release. Necesita VLC instalado.
- **Windows:** descomprime `eterotv-windows.zip` y abre `eterotv.exe`. Necesita VLC de 64 bits (videolan.org).
- **Fire TV sin USB:** ver [docs/INSTALAR-FIRE-TV.md](docs/INSTALAR-FIRE-TV.md).

Decisiones y estado: [docs/DECISIONES.md](docs/DECISIONES.md).
